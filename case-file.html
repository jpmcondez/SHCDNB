Save points

Your notes always save in this browser. A save point also keeps them in Dropbox, so they're backed up and you can carry on from another device.

Option 1 · Sync to your Dropbox account (any device)

This needs the page to be hosted on https, for example on GitHub Pages. It can't sign in when the page is opened as a file from your computer. Use option 2 instead, or host the page first.

One-time setup, about two minutes:

  1. Go to dropbox.com/developers/apps and click Create app.
  2. Choose Scoped access and App folder, and give it a name such as "Case Files".
  3. On the Permissions tab, tick files.content.write and files.content.read, then click Submit.
  4. On the Settings tab, under Redirect URIs, add this page's address:
  5. Copy the App key from the Settings tab, paste it below and click Connect.

Option 2 · A file in your Dropbox folder (computer with the Dropbox app)

Works in Chrome or Edge, even when the page is opened from your computer. Choose a file inside your Dropbox folder. Every change is written to it, and the Dropbox app syncs it.

Option 2 isn't available in this browser. Use Chrome or Edge on a computer, or use option 1.
